# 钢索猎手 (Titan Blade)

原创第一人称低多边形网页小游戏:用钩索在城区间飞行,绕到巨型怪物背后,以足够的速度斩击后颈(发光处)。

纯静态单文件(`index.html`),three.js r128 走 CDN,无需构建。

## 操作
- 鼠标:转视角
- 左/右键:发射左/右钩索
- 空格:收绳 / 地面起跳
- Shift:喷气加速
- WASD:移动
- E:挥刀 / 被抓时挣脱

## 怪物类型
普通、巨型、抓捕型、扑击型、扯绳型、爬墙型、无视型,各有不同外观和应对方式。

## 运行
直接用浏览器打开 `index.html`(需要联网加载 three.js)。
